\section{Profile}
I do not trust model output, and I build like it. Every tool an agent can reach is a declared
function, every value it extracts is coerced to its declared type before anything downstream reads
it, and a number the model states that no tool produced gets marked unverified rather than shown.
I am a Software Developer at CortexCraft.ai, where that discipline runs a fleet of Gemini Live
phone agents in production.
