\section{Selected Projects}

\textbf{JiraFlow Agent and AI Code-Review Gate} \textit{Python, FastAPI, Jira API, GitHub API, Ollama, React}
\begin{itemize}
  \item Turns a Jira ticket into a branch, a code change and a pull request, one
        \texttt{ai/scrum-<id>} branch per ticket whose commit cites the issue. The agent proposes and
        a human merges, so a wrong edit costs a rejected PR rather than a broken main branch.
  \item The review gate is the part an agent cannot argue past: high-risk changes are blocked from
        approval outright, a rejection requires a written reason that is fed back into regeneration,
        every reviewer action lands in an append-only audit log, and nothing auto-merges.
\end{itemize}
