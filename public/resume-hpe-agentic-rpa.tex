\section{Profile}
I build LLM systems that cannot invent a number. The pattern is the same in everything I ship:
deterministic code holds authority, the model is a constrained component, and any figure it states is
checked against the tool result that produced it. That means numeric guardrails that rewrite
unverified output, retrieval that runs before the model with role filters inside the retriever,
extraction that returns null rather than guess, and human approval gates an agent cannot talk its way
past. Software Developer at CortexCraft.ai, in Python/FastAPI and Java/Spring Boot.
